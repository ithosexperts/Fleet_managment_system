### 🚀 What's New in v1.3.0:

#### 1. Ola Maps Style Road Route Visualizer & Drive Simulation HUD
- **OSRM Road Network Snapping (`web/src/services/routing.ts`):** Automatically traces authentic Indian highway and street corridors between the base depot and destination waypoints with an in-memory cache and haversine straight-line fallback.
- **Dual-Layer Neon Glow Corridor:** Custom Leaflet polylines with an outer 9px emerald aura (`#00d084`) and an inner 4.5px cyan highway core (`#0284c7`) providing distinct, high-contrast visibility against dark map tiles.
- **Glassmorphism Telematics HUD:** Floating overlay displaying real-world road distance in kilometers, estimated drive time in minutes, and an active "Road-Snapped" badge.
- **Animated Drive Simulator:** Interactive real-time cab playback along the road polyline featuring:
  - Custom 3D delivery van marker with pulsating radar locator.
  - Realistic fluctuating speedometer gauge (`42 - 58 km/h`).
  - Interactive scrubbable progress bar (0–100%).
  - Playback speed multipliers (`1x`, `2x`, `4x`).
  - "Follow Cab" dynamic camera centering toggle.
- **Turn-by-Turn Waypoints Drawer:** Slide-out drawer with numbered stops, customer contact details, cargo quantities, and one-click Google Maps external navigation links.
- **Basemap Presets:** 1-click toggles for **"Ola Dark"** (cyberpunk logistics), **"Day Navigation"** (street map), and **"Satellite Hybrid"** (aerial imagery).

#### 2. Enterprise Commercial Security & Operational Hardening
- **Helmet HTTP Security Headers:** Enforced security headers including X-Content-Type-Options, X-Frame-Options, and a customized Content-Security-Policy allowing trusted Leaflet map tile providers, Google Fonts, and Lucide icons.
- **Brute-Force Rate Limiting:** Applied `express-rate-limit` to `POST /api/auth/login` (15 attempts per 15 minutes per IP), returning HTTP 429 Too Many Requests upon excessive failed attempts.
- **CORS Domain Whitelisting:** Enforces `ALLOWED_ORIGINS` to restrict browser REST access exclusively to trusted company domain origins.
- **Sanitized Production Error Handling:** Replaced verbose error messages with safe generic descriptions (`Internal server error during authentication`) to guarantee zero internal schema, table structure, or file path leakage.
- **Password Strength Enforcement:** Mandates a minimum of 6 characters for all newly created driver and manager credentials.

#### 3. Zero-Downtime Hot Database Backups
- **`POST /api/backup/create` Endpoint:** Accessible to Operations Managers, executes an atomic SQLite `VACUUM INTO` command.
- **Persistent Storage Integration:** Backup files are named with ISO timestamps (`backup-YYYY-MM-DDTHH-mm-ss-sssZ.sqlite`) and stored in `DATA_DIR/backups/`.
- **Zero Interruption:** Drivers on active routes can continue logging stop arrivals and uploading proofs without table locking or connection drops during backup execution.

#### 4. Clean Elimination of Mock Data & Google Sheets
- **Mock Store Deleted:** Deleted `web/src/services/mockData.ts` and decoupled `web/src/services/api.ts` from all mock fallbacks, reducing the production frontend bundle by 64 kB.
- **Pristine Data Fidelity:** The web and mobile frontends now display only authentic database records. Empty lists produce informative empty-state views rather than fictitious demo trucks (`DL01TA4920`).
- **Google Sheets Deprecated:** Completely removed legacy `googleSheetsRoutes.ts` and `googleSheets.ts`, streamlining the architecture to SQLite WAL + SAP ONE Portal ERP gateway.

#### 5. Enterprise Internal Android Distribution
- **Direct Company APK Rollout:** Drivers install `TruckTracker-Driver-v1.1.0-debug.apk` directly via download links on the Web portal or corporate releases.
- **In-App OTA Version Telemetry:** Native client continuously queries `GET /api/app-version` to alert drivers when a new APK build is ready for installation.
- **Field Resilience:** Full offline event queueing using Android Room database with UUID idempotency keys to ensure zero data loss across spotty highway connectivity zones.

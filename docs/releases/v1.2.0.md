### 🚀 What's New in v1.2.0:

#### 1. Official HoseXperts Corporate Identity & Loading Screen
- **Official Brand Emblem:** High-resolution HoseXperts logo with official tagline ("working with the flow") rendered on dark and light themes with auto-contrast detection.
- **Smooth App Loading Screen:** Centered frosted glass card with glowing telemetry pulse dot displayed during initial bundle bootstrapping and authentication checks.
- **Native Android Splash:** Updated splash screen configuration for Android 12+ Splash Screen API with seamless icon transitions.

#### 2. Watermark-Free Telematics Maps & Corridor HUD
- **Clean Basemaps:** Replaced third-party watermarked Carto tile endpoints with OpenStreetMap tiles powered by CSS invert filter (`.map-tiles-dark`) for a crystal-clear, watermark-free dark telematics experience.
- **Anti-Flicker Telematics Updates:** In-place marker coordinate animations and tab-guarded polling preventing map blinking during 3s/5s telematics cycles.
- **Direct Live Vehicle Tracking:** Dashboard tracking selector and 1-click `[↗ Track]` button to focus and follow any active moving truck corridor across Delhi-NCR.

#### 3. Driver Tri-Lingual Experience (English, हिन्दी, Hinglish)
- **Three Language Options:** Standard English, pure Devnagari Hindi (हिन्दी), and conversational Hinglish designed specifically for field drivers.
- **Localized UI Dictionary:** Translations covering greetings, trip status, stop arrivals, proof-of-delivery instructions, delay reports, vehicle papers, and navigation labels.
- **1-Tap Header Switcher:** Dedicated pill toggle in the mobile driver header with instant UI updates and `localStorage` persistence.

#### 4. Offline Local Device Persistence & Automatic Sync
- **Local Cache:** In-cab actions and vehicle compliance papers cached locally on device for offline operation in low-connectivity highway zones.
- **Automatic Queue Flushing:** Changes recorded offline automatically queue and flush to the central backend upon internet reconnection, verified by 12s sync heartbeat.

#### 5. Ergonomic Mobile & Desktop Layout Polish
- **Mobile Driver Header Reorganization:** Restructured mobile header into two distinct rows:
  - *Row 1 (Brand & Utilities):* Compact HoseXperts logo + circular Theme Toggle (`☀️`/`🌙`) and Notification Bell (`🔔`).
  - *Row 2 (Telematics & Language):* Tri-lingual switcher pill (`EN | हिन्दी | Hinglish`) + live GPS telemetry badge (`Acquiring GPS 🔄` / `🟢 GPS Connected`).
- **Profile Selector Alignment:** Renamed tab to `Manager` creating the unified trilogy: `Manager | Driver | Admin`.
- **Mobile Safe-Area Insets:** Dynamic `padding-top: calc(46px + env(safe-area-inset-top, 12px))` ensuring zero element clipping or theme toggle overlap on mobile devices.
- **Overview Banner Action Streamlining:** Replaced duplicate "Create Trip" button with direct quick-links to `Live Fleet Radar` and `Today's Schedule`.

#### 6. Traffic Challan Proof Upload & E-Challan Vault
- **Proof Attachment in Form:** Dedicated file picker (`image/*,.pdf`, up to 10MB) in `Log Commercial Traffic Challan` form for attaching scanned paper notice slips or camera radar photos.
- **Inline Proof Upload:** Inline `[Upload Proof]` action on previously logged challans without scans.
- **Interactive Verification Sub-Modal:** Visual e-challan certificate rendering infraction data, location, date, fine amount, and attached document viewer/downloader.
- **Database Migration 7:** Added `vehicle_challans` table with foreign key to vehicles, indexed by status, with proof URL, name, and size tracking.

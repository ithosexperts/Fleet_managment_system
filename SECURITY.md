# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within TruckTracker, please responsibly disclose it by opening a private security advisory on GitHub or notifying the maintainers directly.

Please do not open public issues detailing sensitive security vulnerabilities until they have been reviewed and patched.
